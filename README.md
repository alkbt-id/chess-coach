# Шахматный тренер

**Личный шахматный тренер для macOS: разбор своих партий со Stockfish, задачи из своих же ошибок и Claude в чате рядом с доской.**

Приложение скачивает ваши партии с Lichess, прогоняет каждый ход через Stockfish, находит, где вы зеваете, и превращает эти позиции в задачи. Рядом с доской — чат с Claude: он видит ту же позицию, проверяет варианты движком и сам показывает их на доске.

## Что умеет

- **Анализ.** Своя доска: начальная позиция, FEN, ходы, расстановка в редакторе доски или партия из PGN-файла (файл с несколькими партиями открывается списком; файл можно и перетащить в окно). Дерево ходов как на Lichess: ваши ходы становятся вариантами, шкала оценки и панель Stockfish рядом. Любой ход в тексте кликается и показывает позицию.
- **Репертуар.** Ваши дебюты двумя деревьями — за белых и за чёрных — с разделами по дебютам: первые разделы берутся из ваших партий, у каждого видно, сколько партий и очков в нём. Раздел изучается уроками с Claude: урок — это чат, Claude записывает в дерево только ходы, которые вы решили играть, и ведёт для себя конспект, чтобы следующий урок знал, что пройдено. Ходы на доске сначала пробные, в дерево они попадают кнопкой. Тренировка по памяти: программа ходит за соперника по дереву, вы отвечаете своими ходами там, где пора повторить; верные ответы возвращаются всё реже, ошибки — скоро и ещё раз в той же тренировке. Ваши партии сверяются с деревом: в разделе видно, где вы сами уходите из репертуара, на какие ходы соперников в нём нет ответа и где кончается подготовка; после партии в «Игре» то же самое пишется под результатом. Тренировочная партия с движком: соперник ходит по вашему дереву (туда, что пора повторить, или по варианту, который выбрал Claude), потом Stockfish заданной силы; после партии её можно отдать Claude на разбор. Задачи по дебюту: ваши задачи из партий раздела и задачи Lichess в этом дебюте (в ваш рейтинг на Lichess) — решаются в «Задачах».
- **Обзор партии.** В «Игре», у сыгранной партии или в списке ваших партий: Stockfish смотрит каждый ход и ставит ?! / ? / ?? на неточности, ошибки и зевки, а лучший ход добавляет вариантом. Обзор открывается доской прямо в «Игре».
- **Задачи из ваших ошибок.** Два вида: позиция перед вашим зевком («не зевни») и позиция, где соперник зевнул, а вы не наказали («накажи»). Объяснение, почему ход плохой, строится из линий Stockfish. Решённую задачу можно разобрать на доске прямо в «Задачах».
- **Задачи Lichess по слабым темам.** Рейтинговые задачи Lichess, подобранные под темы, где вы ошибаетесь чаще.
- **Игра на Lichess.** Живые партии с вашего аккаунта. Пока идёт партия, движок, анализ и чат закрыты — Lichess запрещает подсказки.
- **Claude в чате.** Чат сам переключается под то, что на экране: у доски, задачи, партии, раздела репертуара — свой разговор; вернёшься к ним — откроется он. Все чаты — в списке в шапке чата. Выбор модели и усилия. У чата может быть несколько досок, у каждой своё дерево вариантов с разборами; между ними переключаются вкладками над доской. Доски остаются там, где живёт их чат: доски разговора о партиях — в «Игре», о задаче — в «Задачах», урока — в «Репертуаре», о своей доске — в «Анализе». Claude работает через ваш вход в Claude Code (без API-ключа), пользуется доской и Stockfish сам; остальные действия идут в авторежиме Claude Code — безопасные выполняются без вопросов, а разрешение в чате спрашивается только на рискованные.

## Установка

Нужны macOS, Swift (Xcode или Command Line Tools), [uv](https://docs.astral.sh/uv/), Stockfish и [Claude Code](https://code.claude.com/docs), в котором вы вошли в аккаунт (только для чата).

```bash
brew install stockfish uv
git clone https://github.com/alkbt-id/chess-coach.git
cd chess-coach
uv sync
./scripts/fetch_sounds.sh   # звуки ходов Lichess; без них приложение работает беззвучно
./mac/build.sh
open ~/Applications/Шахматный\ тренер.app
```

`mac/build.sh` собирает окно в `~/Applications/Шахматный тренер.app` и запоминает в нём, где лежит папка проекта. Если перенесёте папку, соберите окно заново. Окно само запускает локальный сервер на `127.0.0.1:8737`. Без окна сервер запускается так: `uv run python -m coach`, интерфейс — в браузере на <http://127.0.0.1:8737/>.

## Настройки

Чтобы приложение знало, чьи партии разбирать, войдите в Lichess в приложении (вкладка «Игра»). Больше ничего настраивать не нужно.

Остальное — по желанию: скопируйте [config.example.toml](config.example.toml) в `~/Library/Application Support/ChessCoach/config.toml` и заполните нужные строки. По умолчанию все они пустые.

- `lichess_user` — ник на Lichess. Нужен, если не хотите входить в Lichess в приложении;
- `stockfish` — путь к Stockfish, если он не в `/opt/homebrew/bin` или `/usr/local/bin`;
- `about` — пара слов о себе для Claude в чате.

## Свои партии и задачи

Задачи строятся из ваших партий в три шага, четвёртый печатает сводку ошибок. Всё это запускается из приложения (фоновые задания) или из терминала:

```bash
uv run scripts/fetch_games.py    # новые партии с Lichess → lichess/games.ndjson
uv run scripts/analyze.py        # Stockfish по каждому ходу → analysis/moves.jsonl
uv run scripts/make_puzzles.py   # задачи из ошибок → puzzles.json
uv run scripts/report.py         # сводка: точность, ошибки по фазам и по времени
```

## Где лежат личные данные

Токен Lichess, чаты, партии, прогресс по задачам и `config.toml` лежат вне папки проекта, в `~/Library/Application Support/ChessCoach/`. Поэтому они не попадают в репозиторий и общие для всех копий проекта (git worktree).

Для опытов нужна отдельная папка данных, чтобы не трогать настоящие. Сервер рядом с запущенным приложением:

```bash
uv run python -m coach --home /tmp/coach-test --port 8738   # то же: COACH_HOME=/tmp/coach-test COACH_PORT=8738
```

`COACH_HOME` переносит все данные, `COACH_DATA` — только состояние приложения (`app/`), а партии и задачи берутся настоящие.

Тестовую папку можно собрать из копии настоящей: `lichess/`, `analysis/`, `puzzles.json`, `config.toml`. Чаты (`app/chats/`, `app/chats.json`) не копируйте: каждый чат продолжает свой разговор в Claude Code, и тестовые сообщения попадут в настоящий разговор.

## На iPad

Окно на Mac работает через `http://127.0.0.1:8737`. Чтобы открыть приложение на iPad в той же домашней сети, сервер может слушать ещё и сеть — по https и только с ключом ([coach/lan.py](coach/lan.py)):

```bash
brew install mkcert
uv run python -m coach.lan   # сертификат на имя Mac и ключ; печатает ссылку и копирует её в буфер
```

1. Перезапустите приложение: сервер начнёт слушать `https://<имя-mac>.local:8443`.
2. Отправьте на iPad через AirDrop корневой сертификат — `rootCA.pem` из папки, которую печатает `mkcert -CAROOT`. На iPad: «Настройки → Профиль загружен → Установить», затем «Настройки → Основные → Об этом устройстве → Доверие сертификатам» → включите mkcert.
3. Откройте на iPad ссылку с ключом. Ключ запоминается, дальше хватает адреса без него. Значок «На экран Домой» делайте прямо со ссылки с ключом.

Mac при этом должен быть включён и не спать. Выключить: удалите `tls/` в папке данных и перезапустите приложение. Вход в Lichess делается только на Mac.

## Claude Code вне приложения

[coach/mcp_server.py](coach/mcp_server.py) даёт Claude Code в терминале или редакторе те же инструменты доски, что и чату в приложении:

```bash
claude mcp add --scope local chess-board -e PYTHONPATH=$PWD -- $PWD/.venv/bin/python -m coach.mcp_server
```
